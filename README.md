# A Gift for Madhurima 💛

Interactive romantic website with:

1. **Gift box** – Tap to open
2. **Secret date unlock** – Enter the special date (20 October)
3. **Happy Birthday Madhurima** + live countdown to Oct 20, 2026
4. **Fireworks/crackers** when the countdown reaches zero
5. **Loyalty quotes** + her photos
6. **Music** – Lana Del Rey “Young and Beautiful” style

---

## How to use (important for music)

1. Download a soft instrumental / piano version of **“Young and Beautiful”** (or any romantic song you like)
2. Rename the file exactly to:  
   `young-and-beautiful.mp3`
3. Put it in the **same folder** as `index.html`
4. Open `index.html` in browser

(Music button is at bottom-right if autoplay is blocked)

---

## Correct date answers (any of these work)

- 20/10/2026  
- 20-10-2026  
- October 20  
- 20 October 2026  
- oct 20  

---

## Upload to GitHub Pages

1. Create a new **Public** repository
2. Upload these files:
   - `index.html`
   - `photo1.png`
   - `photo2.png`
   - `young-and-beautiful.mp3` (optional but recommended)
3. Go to **Settings → Pages**
4. Source → Deploy from branch → `main` → `/ (root)` → Save
5. Site will be live at:  
   `https://YOUR-USERNAME.github.io/REPO-NAME/`
